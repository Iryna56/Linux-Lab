# Linux-Lab

## Über dieses Repository

Dieses Repository dokumentiert meine praktischen
Linux-Übungen im Rahmen meiner Umschulung zur
Fachinformatikerin für Anwendungsentwicklung (IHK).

## Entwicklungsumgebung

- Betriebssystem: AlmaLinux
- Virtualisierung: Virtuelle Maschine
- Shell: Bash
- Versionsverwaltung: Git und GitHub

- Lokale Namensauflösung mit /etc/hosts

und Dokumentation möglicher Optimierungen.
