# Backup und Automatisierung unter Linux

## Aufgabenstellung

Automatisierung wiederkehrender Aufgaben
und Erstellung regelmäßiger Datensicherungen
unter AlmaLinux.

## Lernziele

- Cron und Crontab verstehen
- Zeitgesteuerte Aufgaben konfigurieren
- Benutzer- und System-Crontab unterscheiden
- Automatische Backups erstellen
- Anacron kennenlernen
- Fehler bei automatisierten Aufgaben analysieren

## Verwendete Technologien

- Cron
- Cronie
- Crontab
- Anacron
- Bash
- TAR
- XZ-Komprimierung
