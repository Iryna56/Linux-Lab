# Netzwerkkonfiguration und DNS unter Linux

## Aufgabenstellung

Konfiguration, Überwachung und Fehleranalyse
von Netzwerkverbindungen unter AlmaLinux.

## Lernziele

- Netzwerkschnittstellen verwalten
- IP-Adressen und Routing analysieren
- Hostnamen konfigurieren
- NetworkManager verwenden
- Netzwerkverbindungen überprüfen
- DNS-Namensauflösung untersuchen
- Netzwerkverkehr analysieren
- Offene Ports identifizieren

## Verwendete Technologien

- TCP/IP
- DNS
- NetworkManager
- NMCLI und NMTUI
- TCPDump
- Netstat
- Socket Statistics
