# Firewall-Konfiguration unter AlmaLinux

## Aufgabenstellung

Verwaltung und Überprüfung der Linux-Firewall
mithilfe von Firewalld.

## Lernziele

- Grundlagen einer Firewall verstehen
- Firewalld verwalten
- Firewall-Zonen kennenlernen
- Aktive Firewall-Regeln überprüfen
- Netzwerkdienste und Ports kontrollieren

## Verwendete Technologien

- Firewalld
- Firewall-CMD
- Systemd
- TCP/IP

## Praktische Übungen

- [Firewalld konfigurieren und überprüfen](firewalld.md)

## Erkenntnisse

Eine Firewall kontrolliert den Netzwerkverkehr
und unterstützt den Schutz vor unerwünschten
Netzwerkzugriffen.
